# ゲーム全体設計（Violated Princess 調 拠点型RPG）

## コンセプト

- **ジャンル**: 2D 見下ろし型（トップダウン）RPG
- **参考作品の構造**: Violated Princess のように「1つの拠点となる町」を起点とし、町から各種ダンジョンへ出発 → 攻略 → 町へ帰還、を繰り返しながら物語が進行する
- **主人公**: 女性キャラクター 1 名（プレイアブル）
- **エンジン**: Godot Engine 4.x（GDScript）
- **描画スタイル**: 2D ドット絵（ピクセルアート、48x48 or 32x32 タイル基準）
  - 理由: 無料アセット・AI 生成との親和性が最も高く、少人数開発で最も現実的

## ゲームループ（将来像）

```
[町（拠点）]
  ├─ 自宅/宿屋: 回復・セーブ
  ├─ ショップ: 装備・アイテム購入
  ├─ ギルド/酒場: クエスト受注・物語イベント
  └─ 町の出口 → [ワールド選択 or マップ移動]
        └─ [ダンジョン1..N]: 探索 → 戦闘 → ボス → 報酬 → 町へ帰還
```

## P1 プロトタイプの要件（今回作るもの）

1. タイトル → 町シーンへ遷移（最低限のタイトル画面）
2. 町マップ（TileMapLayer ベース、建物・道・木・柵などで構成）
3. 女性主人公キャラ
   - WASD / 矢印キーで 8 方向移動（アニメは 4 方向）
   - 歩行アニメーション（上下左右 × 3〜4 フレーム）
   - 建物や障害物との衝突判定
4. カメラ追従（Camera2D、マップ端でクランプ）
5. （任意）BGM 1 曲・足音 SE

## 技術方針

- **Godot 4.x / GDScript**、シーンは小さく分割し `player.tscn` のように再利用可能に
- マップは **TileMapLayer**（Godot 4.3+）で作成。タイルに物理レイヤーを設定し衝突判定はタイル側に持たせる
- キャラ移動は `CharacterBody2D` + `move_and_slide()`
- アニメは `AnimatedSprite2D`（スプライトシートから SpriteFrames を作成）
- シーン遷移・共有状態は autoload（`game_manager.gd`）で管理
- 解像度: 640x360（viewport）を整数スケール（ピクセルアート向け設定: `stretch/mode=viewport`, `scale_mode=integer`, テクスチャフィルタ Nearest）
